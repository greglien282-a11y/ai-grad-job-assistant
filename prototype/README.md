# 启程 Pathwise · 可交互原型 v0.2

> **当前阶段：前端交互演示。** 本页面不包含真实 AI 服务、账号体系或云端数据存储。

本目录展示 AI 应届生求职助手 V0.3 的初步原型，重点验证三个首次使用入口与“经历挖掘 → 岗位匹配 → 简历候选 → 模拟面试复盘”的体验。

## 本地体验

下载本目录三个源文件到同一文件夹，双击 `index.html` 即可打开，无需安装依赖或构建工具。

- `index.html`：页面骨架与弹窗容器
- `styles.css`：响应式排版、卡片与动态虚化背景
- `app.js`：页面路由、演示数据与交互逻辑

## 核心设计

- **首页三个入口**：已有简历、从零整理经历、已经找到目标岗位。
- **轻量流程说明**：点击“了解完整流程”查看产品闭环，不在首页堆叠功能列表。
- **个人空间**：通过头像菜单访问经历库、岗位定制、面试和复盘。
- **简历真实性**：演示区分用户自述、待确认事实与暂不能直接写入的内容。
- **模拟面试**：快速、标准、深度模式示例；支持提前结束和复盘。

## 重要边界

所有分析文本和面试反馈为静态或规则化模拟内容，**不是模型真实推理**；数据仅用于体验流程。登录、文件解析和长期保存均尚未实现。

页面从已验收的“首页 V2 单文件交互演示”拆分为三个源文件，便于后续按模块开发。视觉与业务交互还会继续优化。
