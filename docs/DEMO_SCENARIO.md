# 功能理念示例（虚构案例）

> 本文件是为了说明设计思路而构造的示例，不是真实用户资料，也不是产品已经可运行的截图或记录。

## 用户原始描述

“我用 Python 做过一个图像识别课程设计，参与了数据集整理和模型训练。”

## AI 追问的目标

- 用户自己具体编写过哪些代码？
- 数据集中哪些事情是其亲手完成？
- 是否修改过训练参数，能否记得对应证据？
- 能否解释所写进简历的技术概念？

## 用户确认后的候选表达（假设这些事实均被确认）

“使用 Python 编写图像基础处理脚本，参与图片及标签整理；基于已有模型训练程序开展训练实验，调整学习率等训练配置，观察模型预测结果与训练指标。”

## 重要边界

若用户只运行过现有代码，不能写成“自主研发深度学习模型”；若没有原始日志，不能捏造 mAP、Accuracy 等指标的具体数字；涉及团队成果时必须区别个人贡献。

## 接着做什么

导入目标 JD → 对照真实经历给出岗位相关性解释 → 生成可撤销的改写建议 → 选择是否进行 3 题快速复习。
