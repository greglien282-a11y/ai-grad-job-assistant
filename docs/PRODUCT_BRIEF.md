# 公开版产品需求摘要（目标版本 V0.3）

> 本文是面向 GitHub 展示的精简需求介绍，并非完整内部 PRD。所有「目标」均表示产品计划，除特别注明外尚未实现。

## 产品功能

### F01：真实经历库

输入：旧简历、自由文本、用户回答。输出：教育、课程、项目、技能等事实卡片。  
事实状态：`用户自述确认` / `有材料辅助核实` / `待确认` / `已否认`。  
约束：未确认的事实不能直接进入正式简历。

### F02：AI 经历挖掘

一次问 1–2 个高价值问题。帮助回忆实际做过的工作、个人职责和可验证结果；即使用户停止回答，也能形成阶段性候选项目卡。对于多选题，谨防暗示性选项诱发虚假记忆。

### F03：JD 解析与求职策略

解析岗位描述、区分硬性条件/加分项；识别 `已证实匹配`、`待核实`、`真实能力缺口`。岗位策略先于机械改写。

### F04：一岗一简历

维护基础档案和岗位对应版本，突出与 JD 相关的真实经历；给出修改理由、前后对比、编辑和回退操作。必要时保留原句，不强行“千岗千面”。

### F05：掌握这份简历

简历生成后可选进入快速复习；后续支持标准模拟和深度追问。每轮一题、允许跳过/结束、区分记不清事实和不会概念，完成后形成复盘卡。详见 [面试模式设计](INTERVIEW_MODES.md)。

## 首次体验

三个平行入口：`我已经有简历` / `我还没有一份像样的简历` / `我找到了一份目标岗位`。  
设计目标：前几分钟展示可见价值，完整首次体验争取控制在 10–15 分钟以内，需真实用户测试验证。

## 最小交付标准（目标）

- 简历内容导入或手工录入；经历事实可确认、修改、否认。
- 粘贴 JD 获得结构化要求和策略建议。
- 为指定 JD 生成可对照、可编辑的简历，用户确认后可导出 PDF。
- 提供可选 3 题快速复习和结束复盘。
- 隐私、数据删除和 AI 内容核对机制具备最基本的工程保障。

## 不在最小闭环中强制实现

全网职位聚合、浏览器插件、自动投递、复杂会员/支付体系、无人监督的自动操作。
