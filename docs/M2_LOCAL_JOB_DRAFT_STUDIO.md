# M2 工作包 E：岗位策略、用户简历草稿与主动恢复

本PR堆叠于工作包D（#64），D又依赖未合并#61 `e36499c5d9e01aacb4754c62d520ee02b28d91e4`；main核验为 `e1eff78fd43e424ab22996b182e0e5f4d6bd609c`。最终D依赖SHA与本PR精确HEAD见PR描述。两个产品PR，不另开文档型小PR；#62/#63不改，不Ready/Merge/Deploy。

## 一条真正可操作的本地旅程

首页路径A或`/resume-lab` → 粘贴/本地UTF-8简历 → 核对候选段落与Unicode引用 → 粘贴JD/公开合成视觉算法实习JD → 核对必备/加分/待核实 → 用户自评与原句字面关联 → 勾选/重排/编辑草稿 → 主动下载JSON → 刷新清空 → 重新导入文件恢复 → 本地排版/浏览器打印 → 三题复习。

不是固定经历样例点击器：经历来自用户实际选择的本地文件或文字。开发与浏览器验收只使用公开合成资料。无真实项目/量化指标的应届生也能保留课程作业、教育和技能的真实边界；系统不会为走完流程生成业绩、技术、部署或学历。

## 用户草稿与可信预览分开

此页只生成 `user_draft_not_verified`。用户自己编辑的内容可在本页独立的**用户自述草稿**中展示/打印，旁边明确保留原文与“用户改写”标记；不成为FactV3、分类声明、审核或G4平台认证，不进入原`/jd-lab`受限可信打印。

计划、团队、否定、不确定等有限风险标记仅用于保守展示：原句归入“背景、计划与限制 · 不是已完成个人贡献”；用户改写不能去掉已知来源限制后继续打印。引用即使手工截短，仍检查其原始段落的上下文，跨段引用检查覆盖内容。真正无关的其他段落不因同份简历有计划而整份永久阻断。有限词法不是通用语义认证，未识别近义表达仍是剩余风险。

本地拒绝按精确原句保留，冲突/重复组先整体判断，不按输入顺序放行。不同来源ID不能清除当前内存已有的精确拒绝；撤销和恢复旧草稿会合并当前保留的拒绝列表。没有force/换key/确认解锁。它不是正式FactChange历史，**刷新后状态清空、文件可被人为修改，因此无法证明完整拒绝历史或解决R03语义防复活**。正式R03与G4 BLOCK不因本地演示关闭。正式FactV3不同ID/状态冲突仍由#61原规则与原测试保护，未复用本地草稿状态替代正式合同。

岗位关联只使用有限字面词汇。没有找到原文不等于“没有能力”；只有用户明确自评才标“真实能力缺口”。“可以直接说明”也只是用户自评，需要有字面来源、未改原文且无已知边界冲突，不是熟练度或学历资格认证。用户调整条件保留JD原引文/CP区间；已知矛盾条件继续待核实。

## 严格本地草稿合同

`local-job-resume-draft-v1`独立于正式DTO/CO：

- 固定合同与`user_draft_not_verified`，完整D工作台原文/候选/手工声明。
- JD原文、固定引文位置、有限条件、人工调整标记、自评判断。
- 每条草稿与唯一来源条目双向完整对应；选用、顺序、原文/用户编辑状态严格验证。
- 本地拒绝原句、排版密度、三题进度/回答；没有Bearer、操作键、认证回执或数据库身份字段。

用户主动下载/导入JSON；最大512KiB，UTF-8严格解码。版本/未知字段、重复键（含Unicode转义同名键）、图关联、引用、重复ID、选用类型、文字状态、JD引文、复习状态不符，整份安全拒绝并清除旧结果，无部分响应/旧合同回退。私钥等疑似凭证同D规则拒绝，规则不是完备DLP。字段可被人编辑，UUID和合同合法性不提供防篡改/真实性认证。

文件含完整原文、用户编辑与回答，下载前明示用户自行保管。无localStorage/sessionStorage、账户同步、后台自动保存、网络上传、遥测、Provider或API请求。恢复是本地文档恢复，不执行数据库写入、回执重放或GET。异步文件/恢复通过generation和组件生命周期隔离过时结果。

修改原始材料/结构清除下游岗位与草稿，避免沿用旧引用；撤销仅限当前文档最多30步内存快照，拒绝记录不回退。修改选择、内容、顺序或策略会清空旧复习，三题重新绑定实际可打印条目/原始引用和岗位条件。回答不变成证据。
