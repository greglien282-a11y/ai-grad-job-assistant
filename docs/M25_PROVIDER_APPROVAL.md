## 先回答是否值得调用

未来试验只验证：对固定的公开合成材料，真实模型能否在当前严格候选合同中，比确定性关键词基线给出更有用、可解释且不增加事实的建议。先完成人工标注和争议冻结；没有金标准的软性维度保留不确定，不能以格式正确或自我打分宣称模型已达标。模型返回 JSON 仍须本地完整校验；结构化输出不能证明引用真实性或自然语言保真。

本轮 `local-suggestion-candidates-v1` 只是审核候选，不能产生正式 Fact、分类依据、CO3 或回执。未来外部适配器必须独立审查、在受控服务端执行，不能把密钥放入 Vite 环境、浏览器、草稿文件或 CI artifact；目前外部模式明确拒绝，不提供把 UI 开关改成 real 的路径。

以下是待试验名单，不是已测优胜者。最终批准必须固定实际模型 ID / 快照、账户、地域、推理范围、价格版本、请求合同和合成案例 SHA。别名会变化；没有可固定快照时须显式记录不可复现风险。

- **通义千问 Flash（当前文档候选 `qwen3.8-flash`）**：优先评估轻量文本建议的成本和交互延迟。官方页面列出北京地域与结构化输出能力；这不证明 Pathwise 任务质量、账户开通状态或当下网络可用性。[模型能力](https://help.aliyun.com/zh/model-studio/qwen3-8-flash)
- **通义千问 Plus（候选固定快照 `qwen3.7-plus-2026-05-26`）**：作为更强模型对照，研究其对团队、计划、否定与澄清的收益是否值得额外成本。官方页面说明 `qwen3.7-plus` 当时对应该快照，能力随地域 / 部署范围有差异；不能只核验品牌名。[模型与快照](https://help.aliyun.com/zh/model-studio/qwen3-7-plus)
- **OpenAI GPT-5.4 Mini（快照 `gpt-5.4-mini-2026-03-17`）**：仅作为具备合法支持地区、账户及数据处理条件后的可选结构化对照。官方模型页列出结构化输出；截至本次核验的 API 支持地区列表未列中国内地，因此不作为境内默认方案，不通过代理、转售账号或更换身份绕过地区限制。[模型能力](https://developers.openai.com/api/docs/models/gpt-5.4-mini)、[支持地区](https://developers.openai.com/api/docs/supported-countries)

推荐先审批境内官方供应商的合成小样本对照，再决定是否有理由扩大。没有权重下载、自托管部署、购买 GPU 或开通云服务授权。模型是否“更懂中文”、更少编造或更快均为待测假设。

## 地域与数据处理门槛

阿里云文档区分接入 / 数据存储地域与实际推理部署范围。北京接入不能单独证明所有推理都在同一地点；批准前必须核对实际业务空间、模型、服务范围和账户协议，禁止用全球推理默认值冒充境内处理。[地域与部署范围](https://help.aliyun.com/zh/model-studio/regions/)

其隐私说明称数据不用于训练，同时说明会存储调用产生的数据；必须单独核验留存期限、删除路径、供应商与分包方、访问权限和导出边界，不宣称零留存。[隐私说明](https://help.aliyun.com/zh/model-studio/privacy-notice)

OpenAI 文档也将不用于训练与留存控制分开：默认滥用监测通常涉及最长 30 天记录，端点可能另有应用状态；Zero Data Retention 具有资格和限制。`store=false` 不能代替账户资格、所有保留机制及地域审查。[数据控制](https://developers.openai.com/api/docs/guides/your-data)

这些是公开文档事实，不是本项目已签订的数据处理协议或法律合规结论。条款、模型 / 地域、账单与账户能力在实施前必须重新核验；无法确认则停止，不能自动换区域或供应商。

## 数据最小化方案（待批准）

首轮只允许冻结的公开合成数据，不接 `/resume-lab` 中用户实际导入的文件或资料。即使本地功能支持真实简历，亦不得据此推导外发许可。

拟发送仅包括：匿名案例 ID、合成 JD 的必要条目、选定文本快照及对应 ID / code-point 引用、固定候选 Schema 和安全指令。排除姓名、联系方式、真实学校 / 雇主个人关联、账户凭证、整个文件二进制、完整历史数据库、Bearer、回执和费用账本；用户文字按不可信数据处理，不能成为工具或网络指令。不启用联网检索、文件托管、记忆、工具调用或自动多步代理。

拟只留本地受控证据：案例 / 请求摘要、精确模型和配置、结构化候选、原始失败输出、usage / 延迟 / 账单不确定状态、人工判断。禁止真实资料进入仓库、截图或日志。未来任何真实材料研究须另行同意、脱敏、保留 / 删除政策和审批。

## 失败、降级与人工审核

任意硬性问题立即停该次候选并保留证据：引用错位 / 伪造、数字技能学历新增、计划 / 团队 / 否定限定丢失、拒绝事实重新包装、缺失合同字段、未知版本、PII、提示词注入越权或来源不完整。整轮遇到硬性事实错误、地区不符、账单 / 版本不可核验、越过预算或供应商状态不确定即暂停人工审查，不通过调高 timeout、自动修复 JSON 或改参考答案掩盖。

网络 / 限流 / 格式失败时界面明确不可用，可由用户选择本地规则基线；不能把本地结果标作模型返回，不能自动后台重新调用。建议有用性、真实语义等窄规则无法判定的项必须由独立审核人员标记接受 / 拒绝 / 争议 / 无法判断；任何用户接受仍只形成用户草稿。

3. 原币价格、token / 费用证明、每次 / 总预算、未知费用状态与人工核账；无法封顶时是否接受明确的残余风险。
4. 新适配器和凭据边界代码、安全审查、无自动重试 / 无工具 / 无上传路径、失败停止实验。
5. 审核者、失败处理和取消权限，以及只有通过独立复审才能扩大样本的标准。

批准这些事项也不等于批准正式 typed writer、G4、R03、共享 CO 键域、D4/D5、D6 剩余、D8、部署或真实用户开放。当前 PR 只交付离线候选和审批材料。
