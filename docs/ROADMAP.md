## M2.5 · AI 质量与安全建议候选（本轮 Draft）

本轮以已核验 M2 main 为基线，交付一个独立 Draft PR；未获 Ready、Merge、Deploy 或付费调用授权。

- H：公开合成案例、严格候选解析、独立离线评估器和当前关键词基线对照。
- I：默认关闭的 Mock / fixture 建议实验室；候选、用户决定和原文明确分开，改写只能停留在未经认证的审核草稿。
- J：文档校准、未来 Provider 的独立审批包和真实用户研究的任务 / 指标准备。

案例参考标注默认 `draft_unreviewed`。自动合同检查、窄规则和合成故障结果不能称为模型准确率或事实错误率；真实 AI 质量仍未验证。运行方法及边界见 [M2.5 交付说明](M25_AI_QUALITY_AND_SUGGESTIONS.md)。

## 下一阶段 · 先验证质量，再讨论真实模型

1. 独立人工审核案例和争议，冻结版本；保留未审及无法判断项。
2. 审查离线候选的硬性保真失败和软性实用性，验证人能发现错误改写。
3. 单独批准模型 / 地域 / 数据 / 账单边界后，才可能开发受控合成模型试验；本轮不实现或调用。
4. 单独批准小范围用户研究；先观察合成任务，再讨论真实材料和隐私许可。
5. 正式 typed 写入、可信来源持久化和生产部署另走 G4 / 数据库 / 产品准入。

详见 [Provider 审批准备](M25_PROVIDER_APPROVAL.md) 与 [用户研究准备](M25_USER_RESEARCH_PREPARATION.md)。当前没有真实参与者、真实满意度、节省时间或模型质量结果。
